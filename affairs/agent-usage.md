# 对话里的 agent 怎么用 `affair`

「事项」是他让你替他盯着的一件事。每件事有自己的记录和工作区；**你只通过 `affair` 命令碰它，不要自己去改事项目录里的任何文件**（尤其 `log.jsonl`）。拿不准他是不是这个意思，先问他。

下面写作 `affair`，实际是 `node <affair.mjs 的路径> ...`（路径看这台机器的档案）。

## 他说什么，你跑什么

| 他说 | 你跑 |
|---|---|
| 「帮我盯一下洗牙，月底前要约上」 | `affair new --title 洗牙 --said -` |
| 「那个洗牙的约在下周三了」（补一句） | `affair note 洗牙 --said -` |
| 「刚才那句不对，不用记」（10 分钟内） | `affair undo 洗牙` |
| 「不用盯了」「办完了」 | `affair stop 洗牙 --said -` |
| 「先放一放，下个月再说」 | `affair pause 洗牙 --until "2026-12-02 09:00" --said -` |
| 「接着盯洗牙」 | `affair resume 洗牙` |
| 「你在盯什么」 | `affair ls`；一件的详情 `affair show 洗牙` |
| 他回答了一个问题（编号 D3-1） | `affair answer D3-1 --said -` |
| 他点名要跑某个流程（「用 XX 来做」） | 先 `affair flow <事项>` 看这件事能起哪些；再 `affair flow <事项> <流程> --said-seq <他说的那一行>` |

- **原话一律走标准输入**：`--said -`，把他这一轮说的话原样管进去（PowerShell 里写 `$原话 | node … --said -`）。别把中文写在命令行里，也别转述、别改写。
- 名字拿不准就先 `affair find <词>`；命令说有两件都像，就问他是哪件。
- **流程只用 `affair flow` 起。** 不要自己跑编排运行时（`orch.mjs`），不要写输入文件，不要在环境里改 `PASEO_*`：命令会读单子拼好输入、在这件事自己的工作区里起，并且让它在你这一轮结束、对话换新之后还跑着。同一件事同时只跑一个；以前跑过同一个流程要加 `--again`（回执会说）；一天有上限。命令说「没起成」「已经在跑」时照实转告。
- 命令回执的**第一行原样告诉他**（后面几行是给你的）。命令说「没记下」「没放进去」时照实转告，不要说成做好了。
- 有一张已经办完的单子，他又说「盯一下」：`affair new` 会重新盯，并说「之前办完了，这次重新盯」，照样转告。
- 不要把密码、令牌、配对链接写进去；命令会拒收，拒了就说「有个令牌」这样的话。
- 图片和文件：`affair` 收不了。他在那件事自己的对话（Paseo 侧边栏「事项」里的那一行）里发的图，只在那个对话里用，不会存进 `files/`，之后看一眼也看不到；想让它用上，让那个对话把图里的要点记成文字。以前已经存进 `files/` 的照旧。

## 在那件事自己的对话里：记一句和交回不是一回事

- `affair note <事项> --mine` 只往经过里加一行，**不会改卡片上的「现在」**。卡片上的「现在」只有 `affair report --from chat` 会改。
- 每个里程碑（提交了、对方系统里状态变了、他拍板了、产物出来了）当场 `report` 交回新的 status，记住的旧的用 drop 删。回他话之前用 `affair brief <事项> --chat` 的「现在」对一下刚做完的事，不一致先补交。

## 不要做的

- 不要替他回答事项里的问题，不要替他说「不用盯了」：这些只在他本人说了的时候才跑。
- 看一眼的会话（计划自己起的，不是你）只能 `report`、`note`（记自己的观察，不算他说的）和读数；它碰别的命令会被拒，这是故意的。它起不了流程，想建议起就问他。
- 命令出错或连不上 daemon：把命令的原话报给他，不要绕过去自己写文件。
