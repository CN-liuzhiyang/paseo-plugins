# CRS usage

See [the overview](OVERVIEW.md) or [中文说明](OVERVIEW.zh-CN.md) for setup and data boundaries. No credentials or deployment defaults ship with this plugin.

Development: `npm ci`, then `npm run typecheck`, `npm run lint`, `npm test`, and `npm run format:check`. The fixture and HTTP server under `test/` contain synthetic values only. Tests cover discovery, session isolation, mapping, shared reads, intervals, retries, aborts, redirects, and credential scans.

For a disposable Windows verification instance, `node --import tsx test/isolated.ts` writes a temporary home and Pi fixture, prints their locations, and serves fake CRS on loopback. It does not install into an existing daemon or write plugin settings. Before starting, point `HOME` / `USERPROFILE` at that temporary home, `PI_CODING_AGENT_DIR` at its `.pi/agent`, `CLAUDE_CONFIG_DIR` at its `.claude`, and `CODEX_HOME` at its `.codex`, so automatic discovery cannot read real credentials. Use the bundled CLI's foreground `daemon run --home <printed-home>` to preserve those environment overrides. The generated config uses port 16879 and serves the installed app's web UI. Type `account_names` for synthetic display names including long markup-like text and an unavailable account, `cost` for capped range costs, `cost_unlimited` for uncapped costs, `cost_legacy` for missing daily cost fields, `cost_null` for a failed daily cost read, `tokens` for synthetic 30-day token history or `tokens_null` for failed token reads, `pool` for two Pro accounts at 100% and 4% plus two unavailable accounts, `fresh`, `older`, `reset` for three-state UI fixtures, or `integration`, `normal`, `limited`, `missing`, `expired`, `disabled`, `down`, or `slow` in the fixture terminal to change its response. Stop that exact home with `daemon stop --home <printed-home>`. The browser helper uses a sibling Paseo checkout's Playwright installation and local Chromium; it is test tooling, excluded from the plugin package.

The plugin targets the snapshot schema version 1. It never falls back to inference or admin APIs. Real CRS integration is separate from fixture verification.
