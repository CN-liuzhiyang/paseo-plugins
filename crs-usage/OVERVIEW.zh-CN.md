在 Paseo「使用情况」中显示 CRS Key 今日和累计费用，以及授权范围内 Claude / Codex 账号的窗口用量。侧栏「CRS 用量与管理」提供逐账号进度条、已用 / 剩余切换、标为估算的档位折合和无凭据网页入口。共享窗口不能保证下一请求可用多少。

需要支持 usage-source 的 Paseo（SDK 基线 0.14.0-beta.2）及实现只读 `GET /apiStats/api/usage-snapshot` 接口的 CRS。

快照提供 `tokenDays` 时，侧栏「用量」以四色分段条显示新输入、输出、缓存写入和读取，悬停或点按可看各项数量；大数字显示缓存命中率，小数字显示请求数。「今天 / 7天 / 30天」按 CRS 日期在本地汇总，不重新请求，每次打开默认今天；与已用/剩余独立。按模型明细默认折叠，数量以万/亿缩写，模型名保留原名。命中率为缓存读取除以新输入、缓存写入及缓存读取之和；零用量显示「—」。读失败的 null 不当 0，部分未知时不画不完整的占比；旧服务端缺字段或全 null 时隐藏用量区，原生卡不增加内容。

一般不用填设置。自动读取主机 Pi 的 `models.json` / `auth.json` api_key、Claude Code `settings.json` 的 env（`ANTHROPIC_BASE_URL` 加 `ANTHROPIC_AUTH_TOKEN` 或 `ANTHROPIC_API_KEY`）、Codex `config.toml` 选中的自定义 provider 加 `auth.json` API key。不会使用 OAuth 凭据；文件不存在或读不到就跳过。遵从各工具的主目录环境变量；Pi 目录默认为 `PI_CODING_AGENT_DIR` 或 `~/.pi/agent`。

用各候选自己的 key 探测其 origin 下的快照接口。跳过 `api.anthropic.com`、`api.openai.com` 及其子域。JSON 200/401/403 识别为 CRS；其他服务隐藏。按 origin 和凭据摘要在内存缓存，正向 24 小时、负向 10 分钟。HTTP 返回 403 `Management HTTPS required` 时，只尝试同主机名 HTTPS 443，成功后记住管理地址。不会跟随重定向或错误正文里的地址，证书校验保持启用。

`allowedOrigins` / `providerNames` 是可选来源筛选，非空时只探测命中的地址 / provider，两项均填则均需匹配；留空即自动。`managementOrigin` 可显式覆盖所有候选的取数和网页地址，须为 HTTPS origin；请只填写你信任接收这些 key 的管理地址。网页管理按钮在 SPA 前缀留空时打开 `/apiStats/`，填写后打开 Key 管理页，操作遵从网页自身登录权限。

Key 仅在服务端读取，通过 HTTP header 发往配置来源、同主机 HTTPS 管理入口或显式覆盖的管理地址，不进入插件设置或客户端；网页链接不带 key / apiId。同 origin、同 key 合并。读取共用 12 秒最短间隔、9 秒超时 Abort、30 / 60 / 120 / 240 / 300 秒失败退避及少量抖动，遵从 Retry-After；失败明确提示并保留上次成功时间。

费用上限为 null 显示「无上限」，面板不画费用进度条。折合权重为 max20=20、max5=5、pro/plus/team=1、free=0.2，显示「n/m 可用」。用满账号以 100% 保留权重；不可用、状态未知和档位未知账号排除。已重置窗口在折合中按 0% 计入；5 小时缺重置时间而本周已用满且未重置时，5 小时按 100% 计入。其余缺失窗口不参与。较旧但未重置的数据保留数值、降低亮度并纳入折合，标明「含 n 个较旧数据」。逐账号明细不显示已重置窗口的旧值，提示等待新数据；null 格子省略，不可用账号为灰色一行。采集和重置时间均为相对时间，池重置取纳入账号的最早未来重置时间；5 小时因周额度耗尽而按 100% 计入时使用周重置时间。主/次窗口保留未知时长标签，不猜成 5 小时或本周。

原生卡按平台合并账号，复用面板的同一折合函数，显示 5 小时/本周最多两条，标签含「n/m 可用」，另加「今日费用」金额一行，零 details。折合不可得时省略对应条；不显示账号别名、套餐标签、总费用或任何重置时间。完整逐账号图表、折合、采集时间和网页管理按钮在面板，逐账号明细默认折叠。面板遵从当前主题，可选「CRS 夜色」提供深蓝配色。
